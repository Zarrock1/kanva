# Канва

Схемы для рукоделия из фотографии. Загружаешь фото, выбираешь технику и получаешь схему с палитрой и разбивкой на листы для печати.

Всё работает в браузере: фото никуда не отправляется.

## Техники

- Вышивка крестиком (нитки DMC)
- Алмазная мозаика, термомозаика, бисер
- Вязание спицами и крючком
- Мозаика из Lego, пиксель-арт для Minecraft
- Лоскутное шитьё, мозаика из плитки
- Раскраска по номерам
- Многослойный трафарет, гравюра штриховкой, полутона
- Стринг-арт, литофания

## Экспорт

PDF с разбивкой на A4 и другие форматы, PNG, SVG.

## Запуск

Это один файл `index.html` без сборки и зависимостей. Достаточно открыть его в браузере или положить на любой статический хостинг.
